Keep prefab zones during custom-zone reload

Issue #126

Problem

StrongZones holds prefab-derived zones and configuration-derived zones in one cache. The custom configuration reload replaced that cache with a new instance that had only custom zones. Prefab zones then disappeared until the server restarted.

Change

Each source update now keeps the other source list when it rebuilds the chunk caches.

The regression test starts with one prefab zone and one old custom zone, reloads the custom XML, and verifies that the prefab zone remains while the custom zone is replaced. The headless Unity stub now has the small value types that StrongZones needs to run this path.

Scope

This change does not scan prefabs during a custom reload. It keeps the prefab results already obtained by the current server session. A later prefab update still rebuilds from the current prefab scan and keeps custom zones.
