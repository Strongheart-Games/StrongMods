Preserve the branch key that Steam actually writes

Steam appmanifests use BetaKey, but vendor.cs searched for lowercase betakey. The package build IDs and hashes remained valid; only informational branch provenance was lost.

Implementation review Issue #155 scope: build tooling

Decision and boundary

Parse field names without case sensitivity; leave published packages alone

Selected behavior: match appmanifest field names with case-insensitive, culture-invariant rules. Preserve the field value, keep missing fields as JSON null, and retain the exact build ID as the authoritative Steam coordinate.

The existing 2.6.0.14 packages are not rewritten. Their build IDs, runtime labels, and manifested file hashes were verified before this change. Republishing would add risk without repairing authoritative package content.
