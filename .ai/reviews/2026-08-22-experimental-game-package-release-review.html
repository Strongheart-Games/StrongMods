Publish installable experimental game heads

Extend the package-release signal from Steam's stable public branch to the newest installable head across public and latest_experimental. Keep publication human-run because the licensed assemblies and the package write token stay local.

Issue #39

Decision

An experimental promotion is now a release. It opens or updates the same tracking issue as a stable promotion. release.cs then selects that Steam beta branch, vendors the installed assemblies, and publishes the private packages through the existing human-run command.
Steam stateDecisionReason
Newest eligible head is aheadNotify and publishA player or server operator can install it.
Published experimental branch disappearsStay quietBranch retirement does not invalidate its package.
Stable later moves aheadNotify and publish stableThe newest installable head changed again.
Version-named branch changesStay quietIt is a version hint, not an independent release channel.

State and safety

build/ci/game-versions.json records the branch beside each published buildid. Existing rows migrate to public. This state prevents an absent experimental branch from being mistaken for a stable rollback.

The scheduled workflow holds only contents: read and issues: write. It does not receive the licensed game files or the package write token. Package creation and upload remain local.
